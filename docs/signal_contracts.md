# 信号输出与注册模板契约

信号函数名的版本是注册标识，不代表输出键必须带相同版本。
`#[signal]` 仍校验函数名与 descriptor.name 的版本一致性，但模板必须描述
实际的 `k1_k2_k3`，允许历史无版本键和不同版本键。

本次对照 `v0.10.12` 的 Python 输出，修正 34 个历史信号的注册模板，
保留其输出键。包括 `时间区间`、`BUY1`、`TD`、19 个旧 K 线形态信号，
以及 `bar_channel_V230508` 的历史键 `通道V230507`。完整名单与默认键
保存在 `crates/czsc-trader/tests/test_signal_contracts.rs`。

反解析对整个模板做占位符匹配，不再要求 k3 与模板第三段字面相等。
模板参数不一定直接等于调用参数：时间区间的 `t1/t2` 还原为 HHMM 字符串，
涨跌幅的 `t1/t2` 合并为 `span`，伞形线的 `th` 还原其 100 倍编码。
逆变换失败的候选继续匹配其他模板，不能提前终止整个注册表搜索。

回归测试覆盖这 34 个信号的默认/空 K 线键、模板实例化和键往返，
四个动态 k3 的默认/自定义参数还原，以及全量 descriptor 的名称、opcode
唯一性与注册表映射。它不代表所有指标计算分支均已得到验证。
