# 信号输出与注册模板契约

注册模板的版本标记是信号契约的一部分，不能以历史 Python 无后缀输出为理由删除。
本次恢复 34 个原始注册模板，并逐项修正实际 k3 与之完全一致；不是对所有输出
机械拼接函数名。`bar_channel_V230508` 使用 `通道V230508`，三法、分手线保留
完整八位版本。其他已一致的模板（包括 `BS辅助221211`）不改变标记形式。
宏同时校验函数名/注册名一致性，以及 k3 末尾完整连续 ASCII 数字串与注册版本
完全相等（不能用更长数字串包含相同尾部）。本次仅升级目标 k3，不改变 v1/v2/v3
业务分类值；普通十字线仍输出分类 `十字线`。

## 旧键迁移（破坏性变更）

本迁移纳入维护者于 2026-10-15 明确选择的 **1.0.2**，未撤回迁移、增加旧键别名或双协议。
版本号仍为 1.x 不代表旧策略可直接升级；以下迁移与历史数据重建要求保持有效。

函数注册名、调用参数和公开 API 不变。旧无版本键及通道旧版本键不提供静默别名，
反解析不再接受这些旧键，旧策略条件也不会匹配新输出。请更新 Event/Position/策略的
`signals_all`、`signals_any`、`signals_not`、保存的信号字符串、过滤器及缓存；需要

## 参数与验证范围

反解析对整个模板做占位符匹配，不再要求 k3 与模板第三段字面相等。
模板参数不一定直接等于调用参数：时间区间的 `t1/t2` 还原为 HHMM 字符串，
涨跌幅的 `t1/t2` 合并为 `span`，伞形线的 `th` 还原其 100 倍编码。
逆变换失败的候选继续匹配其他模板，不能提前终止整个注册表搜索。

当前注册模板中，相邻占位符只有 `bar_zdf_V221203` 的 `{di}{mode}`，
以及 `tas_ma_base_V221101`、`tas_ma_base_V221203`、
`tas_second_bs_V230303` 的 `{di}{ma_type}`。共享解析器要求相邻参数中的
`di` 为完整非负整数前缀，不能将多位数字的尾部放入 mode/ma_type。
非空数据测试覆盖 di=10/11/100、ZF/DF，以及三个 MA 信号的 SMA/EMA/WMA
参数精确还原和完整信号键/值往返；其中二买信号不代表其笔形态分支已覆盖。

回归测试覆盖这 34 个信号的默认/空 K 线键、模板实例化和键往返，
四个动态 k3 的默认/自定义参数还原，以及全量 descriptor 的名称、opcode
唯一性与注册表映射。它不代表所有指标计算分支均已得到验证。
